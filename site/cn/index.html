五个 agent。有一个在等你。是哪个？

现在写代码，就是一边盯着并行干活的 agent，一边审阅、解锁、拍板。可我们用来跑它们的工具压根不是为这个设计的：终端每个 tab 长得一模一样，IDE 一个窗口只装一段对话，撞到权限确认的 agent 会一声不吭地干等，直到你碰巧去看它。Bento 就是为这件事从头造的。

你的 agent 团队

谁需要你，一眼看清

每个 pane 都知道自己 agent 的状态——工作中、等你输入、已完成、空闲——用同一套颜色 + 图形语言，贯穿 pane 标题栏、侧栏和会话标签。状态来自 agent 协议本身，不靠屏幕启发式猜测。Agent 自己会说话。

  • 十个 agent 开箱即用——Claude Code、Codex、Gemini CLI、OpenCode、Cursor Agent、Copilot CLI、Amp 等等，还能用自己的 API key 接入 Kimi、GLM、DeepSeek。
  • Parallel 与 Focus。全部平铺，或单个对话全屏、其余列表待命。切换只是视图偏好，结构零变化、零丢失。
  • 像 IDE 一样拖 pane——用 drop zone 分屏、停靠、交换。

一等公民的对话

真正的对话，不是抓屏

Agent 通过 ACP（开放的 Agent Client Protocol）接入，每个 pane 都是真对话：流式 Markdown、可折叠的推理、带实时状态与真实 diff 的工具卡片。不是一个眯着眼数字符的终端模拟器。

  • 权限即按钮。看完真实 diff，⌘⏎ 批准；agent 提问时从选项列表里选答案。
  • agent 声明什么能力，composer 就露出什么——斜杠命令、模型/模式切换、用量仪表、图片附件。
  • 点工具卡片里的任意路径，侧边 dock 直接看高亮代码或渲染后的 Markdown。

语音输入

用说的，别打字

在工作区任意处按住说话。松手把转写文本放进 composer，或上滑当场发送。右键长按某个 pane，就是直接说给那个 agent。

  • 识别懂你的对话。词表由屏幕上的 transcript 动态偏置，中英混说也没问题。
  • 零配置。走 Bento relay 开箱即用。想直连也行——Apple 端上、OpenAI、Qwen 三种引擎都支持自带 key。

它跟着你走

合上笔记本，agent 不停工

你的 agent 活在后台 daemon 里，不在 app 里。退出 app、断网、走开：它们继续干活，回来时对话原地恢复。每一段历史会话都留在目录里。

  • 工作区跟着你走。配对的 iPhone 显示同样的 pane、同样的状态、同样的对话——结构双向同步。
  • 端到端加密，无账号。扫码配对是唯一身份；relay 传的是它读不懂的密文。

底层

原生，不是套壳

Swift 一路到底

macOS 用 AppKit/SwiftUI，iOS 用 UIKit/SwiftUI——无 Electron、无 webview。Chromium 套壳烫腿的地方，它待机不动声色。

ACP 是真相来源

agent 通过开放的 Agent Client Protocol、经我们自己的 Swift acpkit 接入；pane 状态是协议真值，绝非抓屏。

daemon 持有 agent

客户端可挂可离；手机和 Mac 能共视同一个 agent。对话存在各 agent 自己的存储里，靠 session/load 恢复。

relay 保持"哑"

只做配对和端到端加密管道——密钥只在你的设备上，智能永不搬到服务端。

隐私

你的东西，在你的机器上

无账号——配对是唯一身份。遥测默认关闭、严格 opt-in：一组闭合的功能计数器，绝不含对话内容。语音音频经 Bento relay 送到语音 provider（密钥在服务端），或用你自己的 key 直连。对话绝不离开你的设备，除非经端到端加密的 relay 发给你自己配对的设备。

常见问题

它支持哪些 agent？

十个预设——Claude Code、Codex、Gemini CLI、OpenCode、Cursor Agent、Copilot CLI、Amp、OpenClaw、Hermes、Antigravity——还能用自己的 API key 接入 Kimi、GLM、DeepSeek，以及任何会说 ACP 的自定义命令。

ACP 是什么？

Agent Client Protocol——一个开放标准，Claude Code、Gemini CLI 等 agent 原生就说这套。正因如此，Bento 拿到的是真 Markdown、真 diff、真权限确认，而不是抓终端屏。

我需要 API key 吗？

不需要。接上你已经在付费的订阅——首次运行帮你装好 agent、走完它自己的登录（Claude、ChatGPT、Gemini、Copilot）。API key 是可选项，不是必需品。

退出 app，agent 会死吗？

不会——它们活在后台 daemon 里。退出、重开，对话原地恢复。

Intel Mac 支持吗？

暂不支持——Apple Silicon，macOS 14+。

多少钱？

app 免费开源（Apache-2.0）。托管便利（比如零配置语音 relay）在 beta 期免费；付费服务以后可能有。自带 key 永远免费。
