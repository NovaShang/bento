五个 agent，一个在等你。是哪个？

写代码如今是在督一队并行干活的 agent——你负责审查、疏通、拍板。可我们跑 agent 的工具不是为这件事造的：终端 tab 长得全都一样，一个 IDE 窗口只装得下一段对话，agent 卡在权限确认上就那么默默等着，直到你碰巧想起来看一眼。Bento 就是为这件事从头造的。

你的 agent 团队

谁需要你——一眼看清

每个 pane 都知道自己 agent 的状态——工作中、等你拍板、已完成、空闲——同一套颜色 + 图形语言贯穿 pane 标题栏、侧栏和会话标签。状态来自协议本身，不靠屏幕启发式猜测：agent 自己开口说话。

  • 开箱即用十款 agent——Claude Code、Codex、Gemini CLI、OpenCode、Cursor Agent、Copilot CLI、Amp 等等——还能用自己的 API key 接入 Kimi、GLM、DeepSeek。
  • Parallel 与 Focus——全部平铺，或单个对话全屏、其余列表待命。切换只是视图偏好，结构零变化、零丢失。
  • 像 IDE 一样拖拽 pane——drop zone 分屏、停靠、互换。

一等公民的对话

真正的对话，不是抓屏

Agent 通过开放的 ACP（Agent Client Protocol）接入，每个 pane 都是一段真对话：流式 Markdown、可折叠的推理过程、带实时状态与真实 diff 的工具卡片。不是终端模拟器对着字符猜。

  • 权限即按钮。看完真实 diff 后 ⌘⏎ 批准；agent 提问时从选项列表里选答案。
  • agent 声明什么能力，composer 就露出什么——斜杠命令、模型/模式切换、用量仪表、图片附件。
  • 点工具卡片里的任意路径，侧边 dock 里直接看高亮代码或渲染后的 Markdown。

语音输入

用说的，别打字

在工作区任意处按住说话。松手，转写文本落进 composer——上滑，当场发送。右键长按某个 pane，就是直接说给那个 agent。

  • 识别懂你的对话。词表由屏幕上的 transcript 动态偏置，中英混说也没问题。
  • 零配置。走 Bento relay 开箱即用。想直连也行——Apple 端上、OpenAI、Qwen 三种引擎都支持自带 key。

跟着你走

合上电脑，agent 继续干

Agent 活在后台 daemon 里，不在 app 里。退出 app、断网、起身走人：它们继续干活，你回来时对话原地恢复。每段历史会话都留在目录里——重新打开，agent 重新拉起，完整 transcript 一并回来。

  • 工作区跟着你走。配对的 iPhone 上是同样的 pane、同样的状态、同样的对话——结构双向同步。
  • 端到端加密，无账号。扫码配对是唯一的身份；relay 搬运的是它自己也读不了的密文。

引擎盖之下

原生，不是套壳

Swift 从头到尾

macOS 上 AppKit/SwiftUI，iOS 上 UIKit/SwiftUI——没有 Electron，没有 webview。Chromium 套壳焐热大腿的时候，它在待机。

ACP 是唯一真相

Agent 通过开放的 Agent Client Protocol 接入，走我们自己的 Swift acpkit；pane 状态是协议真值，从不抓屏。

daemon 持有 agent

客户端随意挂载、断开；手机和 Mac 可以同看一个 agent。对话存在每个 agent 自己的存储里，经 session/load 恢复。

relay 保持哑

只做配对和端到端加密的管道——密钥只在你的设备上；智能永远不上服务器。

你的东西，在你的机器上

无账号——配对是唯一的身份。遥测默认关闭、严格 opt-in：一组封闭的功能计数器，永远不含对话内容。语音音频经 Bento relay 送到语音服务商（key 存服务端），或用你自己的 key 直连。对话永远不离开你的机器——除了经端到端加密的 relay 送到你自己配对的设备。

你会问的，都在这

支持哪些 agent？

十款预设——Claude Code、Codex、Gemini CLI、OpenCode、Cursor Agent、Copilot CLI、Amp、OpenClaw、Hermes、Antigravity——还能用自己的 API key 接入 Kimi、GLM、DeepSeek，以及任何会说 ACP 的自定义命令。

ACP 是什么？

Agent Client Protocol——Claude Code、Gemini CLI 这些 agent 原生就说的开放标准。正因为它，Bento 拿到的是真 Markdown、真 diff、真权限确认，而不是去抓终端的屏。

需要 API key 吗？

不需要。接上你已经在付费的订阅就行——首次运行会帮你装好 agent、走完它自己的登录（Claude、ChatGPT、Gemini、Copilot）。API key 是选项，不是门槛。

退出 app，agent 会死吗？

不会——它们活在后台 daemon 里。退出、重开，对话原地恢复。

Intel Mac 呢？

暂不支持——Apple Silicon，macOS 14+。

收费吗？

App 免费开源（Apache-2.0）。托管的便利服务（比如零配置语音 relay）beta 期间免费；以后可能出可选的付费服务。自带 key 永远免费。
